# بلقن مونتاج الفيديوهات الدينية

بلقن لـ Claude لمونتاج المحاضرات والدروس والكلمات الدينية، من الملف الخام إلى النشر.

**[⬇ حمّل البلقن](downloads/osama-religious-montage.plugin)** · [نسخة zip](downloads/osama-religious-montage.zip) · النسخة ١.٢ · 🌐 [صفحة البلقن](https://aljeerankwq9-hash.github.io/religious_montage/)

## شنو يسوي؟
| المهارة | تسوي |
|---|---|
| التفريغ | تفريغ عربي بتوقيت الكلمة + SRT + قائمة مراجعة |
| شدّ الإيقاع | قص السكتات وأصوات التردد وإعادة توقيت التفريغ |
| صيد المقاطع | ترشيح أقوى المقاطع من المحاضرة الطويلة وقصها |
| القص العمودي | 9:16 يلحق الوجه + فصل الشخص عن الخلفية |
| زوم التأكيد | زوم ناعم عند الكلمات اللي يشدد عليها المتكلم |
| تنقية الصوت | إزالة ضجيج وضبط الصوت على -14 LUFS |
| صوت ← فيديو | ١٦ ثيم، ٦ مؤشرات، ٣ خلفيات، ٤ مقاسات |
| الريل النهائي | كابشن يلمع كلمة بكلمة + هوك واقتباس وخاتمة |
| باقة النشر | عناوين، وصف، هاشتاقات، فصول يوتيوب، غلاف |

## التنصيب
1. حمّل `downloads/osama-religious-montage.plugin` (أو نسخة zip).
2. أرفقه بمحادثة في Claude واضغط **تثبيت** على بطاقة البلقن.
3. اكتب `/` وتأكد إن المهارات ظهرت.
4. ابدأ بجملة عادية: «فرّغ الكلام بالتوقيت» أو «عندي صوت بس أبيه ريل».

## قبل تنشر
- الآيات والأحاديث اللي يقولها المتكلم تطلع من التفريغ الآلي بدون توثيق — راجعها بعينك.
- العناوين والوصف من كلام المتكلم فقط.
- الخلفيات زخرفة ومؤشرات صوت بدون صور ذوات أرواح.
- حقوق المقطع على صاحبه.

## الصفحة
`index.html` هي صفحة البلقن (GitHub Pages). التفعيل: Settings ← Pages ← Branch: `main` / root.

الأدوات مبنية على Whisper (faster-whisper)، YuNet، MODNet، وخطوط SIL OFL (تجوال، IBM Plex Sans Arabic، رقعة عارف).
